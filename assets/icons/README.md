# [ChatGPT] Plugin icons

Original SVG artwork created for Daily Pages. No external icon dependency. Ship this assets directory with the Lua files. Paper calendar uses a 24-unit grid with a black silhouette for grayscale compatibility. Future themes may supply their own icons here with the same meanings and hit targets; do not use emoji fallbacks. Transport uses literal |< and >| with a boxed play/pause control.

## [ChatGPT] Shared transport icons
Original common/*.svg replaces transport text. Theme icon_set may select another directory with identical filenames. Black vector silhouettes render in grayscale and color.
